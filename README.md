# Cosmic Vanguard 🚀

A roguelite space shooter built with HTML5 Canvas.

## Play
👉 [Play now](https://mystall05-jpg.github.io/COSMIC-VANGUARD-/)

## Features
- 3 playable ships
- Roguelite level-up augments
- Multi-phase boss fights
- Meta-progression shop & achievements
- Procedural audio (no asset files needed)

## Controls
- **Mouse / Touch**: Move ship
- **WASD / Arrows**: Move ship
- **P / Esc**: Pause
